# Linux – Общ преглед

Chloros 1.1.0 въвежда вградена поддръжка на Linux за **CLI**и**Python SDK**, което позволява обработка на мултиспектрални изображения без монитор на работни станции, сървъри и крайни устройства NVIDIA Jetson.

{% hint style="info" %}
**Няма GUI на Linux.** Десктоп GUI на Chloros е достъпно само на Windows. Потребителите на Linux взаимодействат с Chloros чрез [CLI](../CLI.md) и [Python SDK](../api-python-sdk.md).
{% endhint %}

***

## Матрица за поддръжка на платформи

| Функция | Windows (GUI) | Windows (CLI/SDK) | Linux amd64 (CLI/SDK) | Linux arm64 / Jetson (CLI/SDK) |
| --- | --- | --- | --- | --- |
| **Графичен интерфейс за настолни компютри** | Да | Н/Д | Не | Не |
| **CLI** | Да | Да | Да | Да |
| **Python SDK** | Да | Да | Да | Да |
| **GPU ускорение (CUDA)** | Да | Да | Да | Да (JetPack 6) |
| **Дебайер с разпознаване на текстури** | Да (Chloros+) | Да (Chloros+) | Да (Chloros+) | Да (Chloros+) |
| **Динамична адаптация на изчисленията** | Да | Да | Да | Да |***

## Поддържани архитектури

| Архитектура | Описание | Метод на инсталиране |
| --- | --- | --- |
| **amd64 (x86_64)** | Стандартни процесори за настолни компютри/сървъри (Intel, AMD) | Пакет `.deb` |
| **arm64 (aarch64)** | Процесори на базата на ARM, предимно NVIDIA Jetson | Пакет `.deb` (JetPack 6) |

## Поддържани дистрибуции на Linux

* **Ubuntu 20.04+** (amd64)
* **Debian 11+** (amd64)
* **NVIDIA JetPack 6** (arm64 — Jetson платформи)***

## Какво получават потребителите на Linux

* **Chloros CLI** — Пълен интерфейс на командния ред за пакетна обработка, автоматизация и скриптове
* **Chloros Python SDK** — Програмен интерфейс Python (`pip install chloros-sdk`) за интеграция в изследователски пипалини и персонализирани инструменти
* **GPU ускорение** — CUDA-ускорена обработка на NVIDIA GPU (настолни и Jetson)
* **Динамична адаптация на изчисленията** — Автоматично откриване на хардуера и оптимизация на стратегията за обработка
* **Всички функции за обработка** — Същият мултиспектрален процесен поток като Windows (калибриране, корекция на винетиране, растителни индекси, всички формати за експортиране)
* **Функции на Chloros+** — Многонишкова обработка, Texture Aware debayer, персонализирани индекси (с лиценз за Chloros+)

## Какво не получават потребителите на Linux

* **Графичен интерфейс за настолни компютри** — Няма графичен интерфейс; цялото взаимодействие се осъществява чрез CLI или Python SDK
* **Програма за преглед на изображения** — Няма интерактивна програма за преглед на изображения, изглед на мрежа или маркери на картата
* **Визуално управление на проекти** — Проектите се управляват чрез команди CLI и извиквания SDK***

## Първи стъпки с Linux

1. **Инсталиране на Chloros** — Вижте [Инсталиране на Linux](linux-installation.md) за инсталиране на пакета `.deb`
2. **Инсталирайте Python SDK** (по избор) — `pip install chloros-sdk`
3. **Активирайте лиценза си** — `chloros-cli login your@email.com 'password'`
4. **Обработете първия си набор от данни** — `chloros-cli process ~/datasets/flight001`

За потребители на NVIDIA Jetson вижте специалното [Ръководство за NVIDIA Jetson](nvidia-jetson-guide.md) за настройка и оптимизация, специфични за платформата.
