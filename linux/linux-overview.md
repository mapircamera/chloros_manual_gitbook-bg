# Linux – Общ преглед

Chloros 1.2.0 осигурява вградена поддръжка на Linux за **CLI**и**Python SDK** — обработка на мултиспектрални изображения без монитор, както и управление на камери LATTICE и светлинни сензори DAQ в реално време — на работни станции, сървъри и крайни устройства NVIDIA Jetson.

{% hint style="info" %}
**Няма десктоп GUI на Linux.**Десктоп GUI на Chloros е достъпно само за Windows. Потребителите на Linux взаимодействат с Chloros чрез [CLI](../CLI.md) и [Python SDK](../api-python-sdk.md). `.deb` добавя**Chloros CLI** в менюто на приложението ви — той просто отваря емулатор на терминал, в който се изпълнява `chloros-cli`.
{% endhint %}

***

## Матрица за поддръжка на платформи

| Функция | Windows (GUI) | Windows (CLI/SDK) | Linux amd64 (CLI/SDK) | Linux arm64 / Jetson (CLI/SDK) |
| --- | --- | --- | --- | --- |
| **Графичен интерфейс за настолен компютър** | Да | Н/Д | Не | Не |
| **CLI** (`chloros-cli`) | Да | Да | Да | Да |
| **Python SDK** (`chloros-sdk`) | Да | Да | Да | Да |
| **Поток за обработка на изображения** | Да | Да | Да | Да |
| **Управление на камери LATTICE (на живо)** | Да (раздел „Камери“) | Да (`chloros-cli lattice`, SDK) | Да | Да |
| **Светлинни сензори DAQ (на живо)** | Да (раздел „Светлинни сензори“) | Да (`chloros-cli daq pool-*`, SDK) | Да | Да |
| **PTP синхронизация на времето (хостът е „grandmaster“)** | Да | Да (`chloros-cli time-sync`) | Да | Да |
| **GPU ускорение (CUDA)** | Да | Да | Да | Да (JetPack 6) |
| **Дебайеринг с отчитане на текстурата** | Да (Chloros+) | Да (Chloros+) | Да (Chloros+) | Да (Chloros+) |
| **Динамична адаптация на изчисленията** | Да | Да | Да | Да |
| **Бекенд като системна услуга** (`chloros-backend.service`) | Не | Не | Да (по избор) | Да (по избор) |
| **Актуализатор на място** (`chloros-cli update`) | Не (стартирайте инсталатора) | Не (стартирайте инсталатора) | Да | Да |***

## Поддържани архитектури

| Архитектура | Описание | Пакет |
| --- | --- | --- |
| **amd64 (x86_64)** | Стандартни процесори за настолни компютри/сървъри (Intel, AMD) | `chloros_<version>_amd64.deb` |
| **arm64 (aarch64)** | ARM процесори — серия NVIDIA Jetson Orin | `chloros_<version>_arm64_jp6.deb` (версия JetPack 6) |

## Поддържани дистрибуции на Linux

* **Ubuntu 22.04 LTS или по-нова версия** (amd64)
* **Debian 12 или по-нова версия** (amd64)
* **NVIDIA JetPack 6** (arm64 — платформи Jetson Orin)***

## Какво получават потребителите на Linux

* **Chloros CLI** — пълен интерфейс на командния ред за пакетна обработка, автоматизация и създаване на скриптове
* **Chloros Python SDK** — програмно-ориентиран интерфейс Python за изследователски работни потоци и потребителски инструменти (може да се инсталира от PyPI, а също така е включен в `.deb` като wheel файл, съвместим с версията)
* **Управление на камери LATTICE** — откриване, свързване, конфигуриране и запис от камери LATTICE и синхронизирани масиви от няколко камери чрез `chloros-cli lattice` и SDK; `.deb` включва средата за изпълнение Arena SDK, необходима за камерите
* **Управление на светлинни сензори DAQ** — свържете сензори DAQ-U/M/E, предавайте калибрирани спектри и записвайте файлове `.daq` чрез `chloros-cli daq pool-*` и SDK
* **PTP синхронизация на времето** — бекендът Chloros изпълнява PTP „grandmaster“, към който камерите LATTICE и сензорите DAQ-E се синхронизират; проверете го с `chloros-cli time-sync`, и го поддържайте в режим на работа без монитор чрез systemd модула `chloros-backend.service` (вижте [Инсталиране на Linux](linux-installation.md#always-on-ptp-for-headless-hosts))
* **Автоматизация на проекти** — стартирайте запазени проекти в режим без графичен интерфейс с `chloros-cli project` и SDK на `open_project`
* **GPU ускорение** — обработка, ускорена чрез CUDA, на NVIDIA GPU (настолни и Jetson)
* **Динамична адаптация на изчисленията** — автоматично разпознаване на хардуера и избор на стратегия за обработка, с възможност за ръчно преопределяне чрез `CHLOROS_STRATEGY` като експертен изход
* **Всички функции за обработка** — същият конвейер като при Windows: калибриране, корекция на винетиране, растителни индекси и всички формати за експортиране
* **Функции на Chloros+** — многонишкова (поточна) обработка, Texture Aware debayer и персонализирани индекси, с платен план Chloros+

## Какво не получават потребителите на Linux

* **Графичен интерфейс за настолен компютър** — няма графичен интерфейс; цялото взаимодействие се осъществява чрез CLI или Python SDK
* **Програма за преглед на изображения** — няма интерактивна програма за преглед на изображения, изглед на решетка или маркери на картата
* **Визуално управление на проекти** — проектите се създават и управляват чрез команди на CLI и извиквания на SDK (самият хардуер — камери, сензори, запис — остава напълно управляем от терминала)***

## Изисквания за лиценз

Достъпът до CLI и SDK изисква **платен план Chloros+ — Copper или по-висок**(Copper, Bronze, Silver, Gold). Безплатният пакет**Iron** няма достъп до CLI/SDK. Това ограничение се налага от бекенда, а не само от CLI:

| Ситуация | Отговор от сървъра |
| --- | --- |
| Не сте влезли в системата | `401` с `error_code: AUTH_REQUIRED` |
| Влязъл в безплатното ниво „Iron“ | `403` с `error_code: PLAN_UPGRADE_REQUIRED` |

`chloros-cli status` работи на всеки план — това е единственият маршрут, който не е ограничен от „вратата“ — така че причината за отказ винаги е видима.

## Първи стъпки с Linux

1. **Инсталирайте Chloros** — вижте [Инсталиране на Linux](linux-installation.md) за инсталирането на `.deb`
2. **Проверете** — `chloros-cli --version` отпечатва `Chloros CLI 1.2.0`; `chloros-cli selftest` изпълнява 7-степенната диагностика
3. **Инсталирайте Python и SDK** (по избор) — `pip install chloros-sdk`
4. **Влезте в системата** — `chloros-cli login your@email.com 'your-password'` (веднъж за всяко устройство и отново след всяко обновяване на пакета)
5. **Обработете първия си набор от данни** — `chloros-cli process ~/datasets/flight001`

За NVIDIA Jetson вижте специалното [Ръководство за NVIDIA Jetson](nvidia-jetson-guide.md) за настройка, специфична за платформата, термично поведение и внедряване на място.
