Потребителите на Chloros+ получават също така многонишкова обработка за максимална скорост.

#### Инсталатор за Windows (GUI + CLI + Backend)

* **Тип файл**: .exe (инсталатор за Windows)

**Стъпки за инсталиране:**

1. Изтеглете горепосочения файл .exe
2. Кликнете два пъти върху инсталатора, за да започнете инсталирането
3. Следвайте указанията на инсталационния помощник
4. Изберете директория за инсталиране (по подразбиране: `C:\Program Files\Chloros\`)
5. На страницата **Избор на допълнителни задачи**оставете отбелязани и двете опции за**Системни настройки** (препоръчително — вижте по-долу)
6. Завършете инсталацията и стартирайте Chloros или Chloros CLI
7. Влезте с вашия [MAPIR Cloud Chloros+ акаунт](https://cloud.mapir.camera/pricing) (или продължете с безплатната версия)

**Опции за системни настройки** (и двете са отбелязани по подразбиране):

| Опция, както е формулирана в инсталатора | Какво прави | Отказ от тиха инсталация |
| --- | --- | --- |
| **Активиране на дългите пътища в Windows** (позволява папките на проектите да се намират на по-дълбоко ниво от 260 символа; препоръчително) | Задава системната настройка `LongPathsEnabled` на Windows за цялата система на стойност 1. Windows се доставя с тази опция изключена, като в този случай нито един път към файл не може да бъде по-дълъг от 260 символа; продуктите на Chloros се намират до около 130 символа под папката на проекта, така че при изключени дълги пъти се отказва създаването на по-дълбока папка на проекта. Влиза в сила за програми, стартирани след инсталирането. Остава активирана и след деинсталиране, тъй като други програми може да разчитат на нея. | `/MERGETASKS="!longpaths"` |
| **Изключване на бекенда на Chloros от сканирането на Microsoft Defender** (много по-бързо заснемане от камерата; препоръчително) | Добавя изключение от сканиране на Microsoft Defender за `chloros-backend.exe` в инсталационната папка, така че защитата в реално време да не сканира всеки файл, който бекендът записва, независимо къде го записва. При висока честота на заснемане сканирането отнема около 30% от честотата на заснемане (77,7 срещу 52,7 заснемания в секунда при непрекъснато заснемане с 9 камери). Няма изключени други програми, а изключението се премахва при деинсталиране. Когато Defender липсва или е блокиран от политика, тази стъпка се проваля без предупреждение и инсталацията продължава. | `/MERGETASKS="!defenderexclusion"` |

При тиха инсталация (`/SILENT` или `/VERYSILENT`) се прилагат и двете опции, освен ако не се откажете чрез показаната стойност `/MERGETASKS`.

{% hint style="success" %}
Инсталаторът добавя папката CLI (`C:\Program Files\Chloros\cli\`) към вашата система `PATH` само веднъж — при преинсталиране или актуализиране вече не се добавя дублиращ запис и се премахват дублиращите записи, добавени от предишни инсталатори. Отворете нов терминал след инсталирането, за да използвате `chloros-cli`. Инсталаторът добавя също така две правила за Windows Firewall за бекенда във всеки мрежов профил: **Chloros Backend (UDP-In)**, за потоци от камери, PTP, mDNS и потока от данни на DAQ-E, и**Chloros Backend (TCP-In)**, ограничено до локалната подмрежа, за актуализация на фърмуера на DAQ-E, при която сензорът се свързва обратно с този компютър, за да събере изображението. И двете се премахват при деинсталиране.
{% endhint %}

#### Linux amd64 (пакет .deb — CLI + бекенд)

* **Тип файл**: .deb (пакет за Debian/Ubuntu)
* **Архитектура**: x86\_64 (amd64)

```bash
sudo apt install ./chloros_1.3.0_amd64.deb
chloros-cli --version     # Verify installation: "Chloros CLI 1.3.0"
```

#### Linux arm64 — NVIDIA Jetson (пакет .deb — CLI + Backend)

* **Тип файл**: .deb (JetPack 6)
* **Архитектура**: aarch64 (arm64)

```bash
sudo apt install ./chloros_1.3.0_arm64_jp6.deb
chloros-cli --version     # Verify installation: "Chloros CLI 1.3.0"
```

Използвайте името на файла, който сте изтеглили, и запазете `./`, за да може `apt` да инсталира този файл, вместо да търси пакет по име. Инсталирайте с `apt install`, а не с `dpkg -i`: apt инсталира и изискванията на Python SDK, които пакетът препоръчва, а не изисква, а `dpkg -i` ги пропуска. От версия 1.3.0 нататък бекендът и CLI-то се инсталират в разпакетиран вид под `/usr/lib/chloros/`, така че те стартират, без първо да се разпакетират.

Пакетът за Jetson използва CUDA версията на PyTorch от JetPack 6, така че обработката, включително Texture Aware debayer, се изпълнява на GPU-то на Jetson. Той използва библиотеките CUDA и cuDNN, които JetPack 6 инсталира (`sudo apt install nvidia-jetpack` на образ, в който те липсват).

Вижте [Инсталиране на Linux](linux/linux-installation.md) за подробни инструкции за настройка и [Ръководство за NVIDIA Jetson](linux/nvidia-jetson-guide.md) за указания, специфични за Jetson.

#### Python SDK (всички платформи)

Всеки инсталатор включва съответстващ `chloros_sdk` wheel, така че версията на SDK винаги съответства на инсталирания GUI/CLI/backend. В Windows инсталаторът го инсталира автоматично в системния Python. В Linux `.deb` инсталира SDK за самата система `python3` (в `/usr/lib/python3/dist-packages`), така че `import chloros_sdk` работи веднага след инсталирането, без pip и без мрежа. Само virtualenv, който не вижда системните пакети, се нуждае от инсталирането на приложенията от пакета в него:

```bash
pip install /usr/lib/chloros/sdk/chloros_sdk-*.whl
```

За хостове, които използват само pip (без инсталиран пакет Chloros; в този случай SDK управлява бекенд на друга машина), SDK също е наличен в PyPI:

```bash
pip install chloros-sdk
```

Вижте [API: Python SDK](api-python-sdk.md) и [Справочник за SDK](reference/sdk-reference.md) за документация.

{% hint style="info" %}
**Потребители на Linux**: Пакетът `.deb` инсталира CLI, бекенда и Python SDK. Няма графичен интерфейс за Linux — цялото взаимодействие се осъществява чрез CLI или SDK.
{% endhint %}

### Python SDK


За разработчици и работни потоци за автоматизация Chloros Python SDK се доставя с всеки инсталатор: инсталаторът за Windows го инсталира във вашия Python, а инсталаторът за Linux `.deb` го инсталира за системния `python3`. ## Помощ при инсталирането

### Отстраняване на проблеми

**Инсталирането се проваля с следното съобщение за грешка:**

* Уверете се, че имате администраторски права
* Временно деактивирайте антивирусния софтуер
* Проверете дали отговаряте на минималните системни изисквания

**Приложението не стартира (Windows):**

* Уверете се, че е инсталиран Windows 10/11 (64-битова версия)
* Актуализирайте графичните драйвери
* Проверете „Програмата за преглед на събития“ на Windows за подробности за грешката
* Свържете се с отдела за поддръжка, като предоставите логовете за грешки

**CLI не стартира (Linux):**

* Уверете се, че пакетът `.deb` е инсталиран правилно: `dpkg -l | grep chloros`
* Проверете правата за достъп: `sudo chmod +x /usr/bin/chloros-cli`
* Изпълнете диагностика: `chloros-cli selftest`
* Проверете за липсващи библиотеки: `ldd /usr/lib/chloros/backend/chloros-backend | grep "not found"` (от версия 1.3.0 нататък `/usr/lib/chloros/chloros-backend` е малък скрипт за стартиране; самата програма се намира в `/usr/lib/chloros/backend/`)

**Проблеми с активирането на лиценза:**

* Уверете се, че интернет връзката е активна
* Проверете данните за вход на [https://cloud.mapir.camera](https://cloud.mapir.camera)
* Проверете дали защитната стена не блокира Chloros

* Вижте [Chloros+ Вход](chloros+-login.md) за подробни инструкции

## Софтуерни актуализации

Chloros проверява за актуализации, уведомява, когато е налична нова версия, и предоставя линк към тази страница за изтегляне — актуализирате, като стартирате новия подписан инсталатор. Настройките, проектите и данните ви за вход се запазват след актуализациите. В Linux и Jetson, `chloros-cli update` проверява за по-нова версия и предлага да изтеглите и инсталирате съответния `.deb` (тази команда е само за Linux).
