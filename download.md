# Изтегляне

Изтеглете най-новата версия на Chloros, за да започнете да работите с мултиспектрална обработка на изображения.

### Системни изисквания

#### Windows

| Изискване          | Минимални                                              | Препоръчителни                                          |
| -------------------- | ---------------------------------------------------- | ---------------------------------------------------- |
| **Операционна система** | Windows 10 (64-битова)                                  | Windows 11 (64-битова)                                  |
| **Процесор**        | Intel Core i5 или еквивалентен                          | Intel Core i7 или по-добър                              |
| **Памет (RAM)**     | 8 GB                                                  | 16 GB или повече                                         |
| **Графична карта**    | Съвместима с DirectX 11                                | NVIDIA GPU с 4 GB+ VRAM                            |
| **Памет**          | 6 GB свободно място                                       | SSD с 10 GB+ свободно място                            |
| **Екран**          | 1920x1080                                            | 2560x1440 или по-висока резолюция                                  |
| **Интернет**         | Необходим за \[опционална\] активация на лиценза Chloros+ | Необходим за \[опционална\] активация на лиценза Chloros+ |

#### Linux amd64 (x86\_64)

| Изискване       | Минимално                    | Препоръчително               |
| ----------------- | -------------------------- | ------------------------- |
| **Дистрибуция**  | Ubuntu 22.04 LTS+ / Debian 12+ | Ubuntu 24.04 LTS      |
| **Процесор**     | x86\_64 (Intel/AMD)        | Intel Core i7 или по-добър   |
| **Памет (RAM)**  | 8 GB                        | 16 GB или повече              |
| **Графична карта** | Няма (обработка от процесора)      | NVIDIA GPU с 4 GB+ VRAM |
| **Памет**       | 2 GB свободно място             | SSD с 10 GB+ свободно място       |
| **Python**        | Python 3.7+ (за SDK)      | Python 3.10+              |

#### Linux arm64 (NVIDIA Jetson)

| Изисквания      | Минимални                      | Препоръчителни                     |
| ---------------- | ---------------------------- | ------------------------------- |
| **Платформа**     | NVIDIA Jetson с JetPack 6 | Jetson Orin NX 16 GB или AGX Orin |
| **Памет (RAM)** | 8 GB (споделена между GPU и CPU)         | 16 GB+ споделена                    |
| **Памет за съхранение**      | 2 GB свободно място               | NVMe SSD с 10 GB+ свободно място        |
| **Python**       | Python 3.7+ (за SDK)        | Python 3.10+                    |

{% hint style="info" %}
**Ускорение чрез GPU**: Потребителите на Chloros+ с графични процесори на NVIDIA могат да използват CUDA ускорение за значително по-бърза обработка. Това работи както на Windows (настолни графични процесори), така и на Linux (настолни графични процесори и NVIDIA Jetson). Потребителите на Chloros+ получават и многопоточна обработка за максимална скорост.
{% endhint %}

#### Инсталатор на Windows (GUI + CLI + Backend)

* **Тип файл**: .exe (Инсталатор на Windows)**Стъпки за инсталиране:**

1. Изтеглете горепосочения файл .exe
2. Кликнете два пъти върху инсталатора, за да започнете инсталирането
3. Следвайте указанията на инсталационния помощник
4. Изберете директория за инсталиране (по подразбиране: `C:\Program Files\MAPIR\Chloros\`)
5. Завършете инсталирането и стартирайте Chloros или Chloros CLI
6. Влезте с вашия [акаунт в [MAPIR Cloud Chloros+]](https://cloud.mapir.camera/pricing) (или продължете с безплатната версия)

{% hint style="success" %}
Инсталаторът автоматично добавя `chloros-cli` към системната ви PATH за достъп от командния ред.
{% endhint %}

#### Linux amd64 (пакет .deb — CLI + Backend)

* **Тип файл**: .deb (пакет за Debian/Ubuntu)
* **Архитектура**: x86_64 (amd64)

```bash
sudo dpkg -i chloros-amd64.deb
chloros-cli --version  # Verify installation
```

#### Linux arm64 — NVIDIA Jetson (.deb пакет — CLI + Backend)

* **Тип файл**: .deb (JetPack 6)
* **Архитектура**: aarch64 (arm64)

```bash
sudo dpkg -i chloros-arm64-jp6.deb
chloros-cli --version  # Verify installation
```

Вижте [Инсталиране на Linux](linux/linux-installation.md) за подробни инструкции за настройка и [Ръководство за NVIDIA Jetson](linux/nvidia-jetson-guide.md) за указания, специфични за Jetson.

#### Python SDK (всички платформи)

Всеки инсталатор включва съответстващ `chloros_sdk` wheel, така че версията на SDK винаги съответства на инсталирания GUI/CLI/backend. При Windows инсталаторът го инсталира автоматично в системата ви Python; при Linux инсталаторът `.deb` поставя колелото в `/usr/lib/chloros/sdk/` и извежда командата за инсталиране:

```bash
pip install --user /usr/lib/chloros/sdk/chloros_sdk-*.whl
```

За хостове, които използват само pip (без инсталиран пакет Chloros), SDK също се намира в PyPI:

```bash
pip install chloros-sdk
```

Вижте [API : Python SDK](api-python-sdk.md) и [SDK Справочник](reference/sdk-reference.md) за документация.

{% hint style="info" %}
**Потребители на Linux**: Пакетът `.deb` инсталира CLI и бекенда. Няма графичен интерфейс за Linux — цялото взаимодействие се осъществява чрез CLI или SDK.
{% endhint %}

## Помощ при инсталирането

### Отстраняване на проблеми

**Инсталирането се проваля с следното съобщение за грешка:**

* Уверете се, че имате администраторски права
* Временно деактивирайте антивирусния софтуер
* Проверете дали отговаряте на минималните системни изисквания

**Приложението не стартира (Windows):**

* Уверете се, че Windows 10/11 (64-битова версия) е инсталиран
* Актуализирайте графичните драйвери
* Проверете „Програмата за преглед на събития“ за Windows за подробности за грешката
* Свържете се с отдела за поддръжка, като предоставите логовете за грешки

**CLI не стартира (Linux):**

* Уверете се, че пакетът `.deb` е инсталиран правилно: `dpkg -l | grep chloros`
* Проверете правата за достъп: `sudo chmod +x /usr/bin/chloros-cli`
* Изпълнете диагностика: `chloros-cli selftest`
* Проверете дали липсват библиотеки: `ldd /usr/lib/chloros/chloros-backend | grep "not found"`

**Проблеми с активирането на лиценза:**

* Уверете се, че интернет връзката е активна
* Проверете данните за вход на [https://cloud.mapir.camera](https://cloud.mapir.camera)
* Проверете дали защитната стена не блокира Chloros
* Вижте [Chloros+ Вход](chloros+-login.md) за подробни инструкции

## Софтуерни актуализации

Chloros проверява за актуализации, уведомява, когато е налична нова версия, и предоставя линк към тази страница за изтегляне — актуализирате, като стартирате новия подписан инсталатор. Настройките и проектите ви се запазват след актуализациите. В Linux и Jetson, `chloros-cli update` проверява за по-нова версия и предлага да изтеглите и инсталирате съответния `.deb` (тази команда е достъпна само за Linux).
