# Изтегляне

Изтеглете най-новата версия на Chloros, за да започнете да работите с мултиспектрални изображения.

### Системни изисквания

#### Windows

| Изискване          | Минимални                                              | Препоръчителни                                          |
| -------------------- | ---------------------------------------------------- | ---------------------------------------------------- |
| **Операционна система** | Windows 10 (64-битова)                                  | Windows 11 (64-битова)                                  |
| **Процесор**        | Intel Core i5 или еквивалентен                          | Intel Core i7 или по-добър                              |
| **Памет (RAM)**     | 8 GB                                                  | 16 GB или повече                                         |
| **Графична карта**    | Съвместима с DirectX 11                                | NVIDIA GPU с 4 GB+ VRAM                            |
| **Памет**          | 6 GB свободно място                                       | SSD с 10 GB+ свободно място                            |
| **Дисплей**          | 1920x1080                                            | 2560x1440 или по-висока                                  |
| **Интернет**         | Необходим за \[опционална] Chloros+ активация на лиценза | Необходим за \[опционална] Chloros+ активация на лиценза |

#### Linux amd64 (x86\_64)

| Изискване       | Минимално                    | Препоръчително               |
| ----------------- | -------------------------- | ------------------------- |
| **Дистрибуция**  | Ubuntu 20.04+ / Debian 11+ | Ubuntu 22.04+             |
| **Процесор**     | x86\_64 (Intel/AMD)        | Intel Core i7 или по-добър   |
| **Памет (RAM)**  | 8 GB                        | 16 GB или повече              |
| **Графична карта** | Няма (обработка от процесора)      | NVIDIA GPU с 4 GB+ VRAM |
| **Памет**       | 2 GB свободно място             | SSD с 10 GB+ свободно       |
| **Python**        | Python 3.7+ (за SDK)      | Python 3.10+              |

#### Linux arm64 (NVIDIA Jetson)

| Изискване      | Минимално                      | Препоръчително                     |
| ---------------- | ---------------------------- | ------------------------------- |
| **Платформа**     | NVIDIA Jetson с JetPack 6 | Jetson Orin NX 16GB или AGX Orin |
| **Памет (RAM)** | 8GB (споделена GPU/CPU)         | 16GB+ споделена                    |
| **Памет**      | 2GB свободно място               | NVMe SSD с 10GB+ свободно        |
| **Python**       | Python 3.7+ (за SDK)        | Python 3.10+                    |

{% hint style="info" %}
**GPU ускорение**: Потребителите на Chloros+ с NVIDIA GPU могат да използват CUDA ускорение за значително по-бърза обработка. Това работи както на Windows (настолни GPU), така и на Linux (настолни GPU и NVIDIA Jetson). Потребителите на Chloros+ получават и многонишкова обработка за максимална скорост.
{% endhint %}

#### Инсталатор на Windows (GUI + CLI + Backend)

* **Тип файл**: .exe (Windows Инсталатор)**Стъпки за инсталиране:**

1. Изтеглете горния файл .exe
2. Кликнете два пъти върху инсталатора, за да започнете инсталирането
3. Следвайте указанията на инсталационния помощник
4. Изберете директория за инсталиране (по подразбиране: `C:\Program Files\[USER]\Chloros\`)
5. Завършете инсталирането и стартирайте Chloros или Chloros CLI
6. Влезте с вашия [MAPIR Cloud Chloros+ акаунт](https://cloud.mapir.camera/pricing) (или продължете с безплатната версия)

{% hint style="success" %}
Инсталаторът автоматично добавя `chloros-cli` към системния PATH за достъп от командния ред.
{% endhint %}

#### Linux amd64 (.deb пакет — CLI + Backend)

* **Тип файл**: .deb (пакет за Debian/Ubuntu)
* **Архитектура**: x86\_64 (amd64)

```bash
sudo dpkg -i chloros-amd64.deb
chloros-cli --version  # Verify installation
```

#### Linux arm64 — NVIDIA Jetson (.deb пакет — CLI + Backend)

* **Тип файл**: .deb (JetPack 6)
* **Архитектура**: aarch64 (arm64)

```bash
sudo dpkg -i chloros-arm64-jp6.deb
chloros-cli --version  # Verify installation
```

Вижте [Инсталиране на Linux](linux/linux-installation.md) за подробни инструкции за настройка и [Ръководство за NVIDIA Jetson](linux/nvidia-jetson-guide.md) за указания, специфични за Jetson.

#### Python SDK (Всички платформи)

```bash
pip install chloros-sdk
```

Вижте [API : Python SDK](api-python-sdk.md) за документация.

{% hint style="info" %}
**Потребители на Linux**: Пакетът `.deb` инсталира CLI и бекенда. Python SDK се инсталира отделно чрез pip. Няма графичен интерфейс за Linux — цялото взаимодействие се осъществява чрез CLI или SDK.
{% endhint %}

## Помощ при инсталирането

### Отстраняване на проблеми

**Инсталирането се проваля с следното съобщение за грешка:**

* Уверете се, че имате администраторски права
* Временно деактивирайте антивирусния софтуер
* Проверете дали отговаряте на минималните системни изисквания

**Приложението не стартира (Windows):**

* Уверете се, че Windows 10/11 (64-bit) е инсталиран
* Актуализирайте графичните драйвери
* Проверете Windows Event Viewer за подробности за грешката
* Свържете се с поддръжката с логовете за грешки

**CLI не стартира (Linux):**

* Уверете се, че пакетът `.deb` е инсталиран правилно: `dpkg -l | grep chloros`
* Проверете правата за достъп: `sudo chmod +x /usr/bin/chloros-cli`
* Изпълнете диагностика: `chloros-cli selftest`
* Проверете за липсващи библиотеки: `ldd /usr/lib/chloros/chloros-backend | grep "not found"`

**Проблеми с активирането на лиценза:**

* Уверете се, че интернет връзката е активна
* Проверете данните за достъп на [https://cloud.mapir.camera](https://cloud.mapir.camera)
* Проверете дали защитната стена не блокира Chloros
* Вижте [Chloros+ Вход](chloros+-login.md) за подробни инструкции

<summary>Версия 1.1.0 (Последна)</summary>

**Дата на издаване: март 2026 г.**

**Нови функции*** **Поддръжка на Linux** — Родна поддръжка на CLI и SDK за Linux amd64 (x86\_64) и arm64 (NVIDIA Jetson JetPack 6). Инсталирайте чрез `.deb` пакети.
* **Поддръжка на NVIDIA Jetson** — Оптимизирана обработка за крайни устройства Jetson Nano, Orin Nano, Orin NX и AGX Orin.
* **Динамична адаптация на изчисленията** — Автоматично откриване на хардуера и оптимизация на стратегията за обработка. Chloros се адаптира към вашия хардуер — от Jetson Nano до работна станция с няколко графични процесора.
* **4-нишкова тръба за обработка** — Едновременни нишки за откриване, калибриране, обработка и експортиране с динамично разпределение на паметта на графичния процесор.
* **Нови команди CLI** — `selftest` (системна диагностика) и `update` (управление на актуализациите на Linux).
* **Нови флагове на процеса CLI** — `--debayer` (стандартен/съобразен с текстурата), `--indices` (определяне на индекси), `--target` (първо търсене в целевата подпапка за по-бързо откриване).
* **Нови елементи в менюто на графичния интерфейс** — Добавяне на файлове, Добавяне на папка и Стартиране/Спиране на обработката вече са достъпни от падащото меню на главното меню.**Подобрения**

* Автоматично откриване на междуплатформен бекенд (пътища Windows и Linux)
* Подобрени SDK и `get_status()` с проследяване на напредъка за всеки поток
* Нови изключения в SDK: `ChlorosConfigurationError`, `ChlorosAuthenticationError`
* Термично управление и адаптивно ограничаване за NVIDIA Jetson
* Автоматично управление на паметта с OOM преминаване към обработка на GPU с плочки
